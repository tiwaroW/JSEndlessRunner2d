# JSEndlessRunner2d
Name of game "Endless PaperPlane flight"

Javascript game Endless runner using Canvas2D

## About the game :
Paper plane flies endlessly , trying to travel as far as possible
<br> when the plane encounters a tree in its path , it will fly upward to avoid the obstacle

## Control
Spacebar : Jump / fly up
<br> Spacebar : after Game over Restart the game

## File
### image/ - contains all images used in the game
### Sprite_OBJ.js - the main class used by Cloud.js , tree_OBJ.js , It is also responsible for drawing images onto the Canvas and displaying collision boundaries.
